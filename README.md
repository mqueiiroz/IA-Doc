# 📄 IA-Doc

> Sistema de interação inteligente com documentos utilizando **Inteligência Artificial**.

O **IA-Doc** é um sistema em que o usuário pode criar uma conta, enviar um documento em PDF e realizar perguntas sobre o seu conteúdo.

O sistema processa o documento, identifica os trechos mais relevantes para cada pergunta e utiliza Inteligência Artificial para gerar respostas baseadas nas informações presentes no documento.
